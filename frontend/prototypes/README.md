# Prototype pages (archived)

These are **early UI mockups** from before the app was wired to the API. They
use a different design system (Boxicons / Poppins), are **not linked** from the
running app, contain some broken internal links, and make **no API calls**.

They are kept only for design-history reference. The live application is the set
of pages in [`../`](../):

`index.html`, `admin.html`, `visitors.html`, `complaints.html`, `billing.html`,
`parking.html`, `announcements.html`, `manage-users.html`, `guard.html`,
`resident.html` (+ `sidebar.js`, `js/`).

Safe to delete this whole folder if you don't need the mockups.
